FAQ

Pertanyaan yang Sering Diajukan

Apakah ARUNA gratis untuk sekolah?

Ya. Aplikasi ARUNA gratis untuk sekolah peserta program MBG. Biaya hanya untuk perangkat keras biodigester BIOSYNC (satu kali).

Perlu instal aplikasi di HP?

Tidak. ARUNA berjalan di browser (HP maupun laptop) dan otomatis menyesuaikan tampilan. Cukup buka aruna-id.web.app dan masuk.

Bagaimana alat terhubung ke internet?

Unit BIOSYNC memakai ESP32 dengan WiFi sekolah. Pengaturan WiFi dilakukan sekali lewat Bluetooth langsung dari browser — tanpa kabel, tanpa aplikasi tambahan.

Apakah biogasnya aman untuk sekolah?

Aman jika SOP diikuti: alat dilengkapi sensor gas MQ-4 dengan ambang peringatan otomatis, dan aplikasi menyediakan checklist keselamatan harian untuk operator.
